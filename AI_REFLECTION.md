# AI Reflection

## Tools Used

I used ChatGPT as an AI tool while completing this lab. I used it to help me understand the assignment requirements, plan the two programs, write a first draft of the C++ code, and understand how to test the programs. I also used OnlineGDB to write, compile, and run the programs.

## One Decision

One design decision was using a named constant called ANNUAL_RATE in ocean_levels.cpp. I kept this suggestion because the annual ocean-level increase is a fixed value of 1.5 mm per year. Using a named constant makes the program easier to read and prevents the rate from being accidentally changed during the calculations.

## Verification

I did not rely only on the AI to determine whether the programs worked. I ran both programs in OnlineGDB and compared the actual output with calculations I made myself. The average program produced a sum of 154 and an average of 30.8 using the assigned values. I also changed the values and got a sum of 61 and an average of 12.2. The ocean-level program produced 7.5 mm, 10.5 mm, and 15 mm using the assigned rate. I also tested a different rate of 2.4 and got 12 mm, 16.8 mm, and 24 mm. All tests matched the expected results.
